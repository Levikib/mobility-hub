# Mobility Hub

Fleet, chauffeur and booking operations for **Executive Mobility Hub** — a demo system
for executive & government transport in Kenya. Next.js 14 (App Router), TypeScript.

Modules: Dashboard · Bookings & Jobs · Availability · Fleet · Chauffeurs · Compliance · Driver Portal.

Pitch/demo environment — data is indicative (KES rates, NTSA/PSV/TSV compliance, LPO/eTIMS flow).
